## 术语约定

| 术语 | 含义 |
|---|---|
| 设备（Device） | 一台运行 gtun-client 的主机，身份是自持的 UUID `device_id` |
| 网络（Network） | 一个虚拟网段（RFC1918 CIDR），成员各分得一个虚拟 IP |
| 配对（Peering） | 网络内一对设备的长期配对关系，落库、跨多次建链存在 |
| 链路（Link） | 一对设备之间的一次隧道连接，运行期状态纯内存 |
| 链路尝试（Attempt） | 一次打洞建链过程，由 token 唯一标识，失败即终态 |
| 画像（Profile） | 客户端对自己 NAT 行为的采样结论：stable（端口可预测）/ variable（端口随机） |
| 打洞（Punch） | 双方互发 UDP 报文在各自 NAT 上开出双向映射的过程 |
| helper | variable 侧为扩大端口覆盖而批量创建的 UDP socket（256/512/1024 三档） |

## 写作约定

- 帧格式用逐字段表格给出（偏移 / 大小 / 字段 / 取值），字节序与上限常量显式标注。
- 代码引用写「文件路径 + 函数/常量名」，不钉死行号（避免代码演进后失效）。
- 涉及取舍论证的小节会注明「删除了什么、为什么删」，防止被回头加回去。
